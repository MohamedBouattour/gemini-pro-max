Declarative Architecture: Plug-and-Play Personas

Instead of hardcoded review roles, every agent is defined as an isolated JSON manifest in .gemini/agents/<agent_id>.json. Engineering teams can customize weights, blocking rules, and model tiers dynamically:

Manifest Specification Schema

  • id & name: Unique identifier and display label in Ink TUI and Companion Web UI.
  • category: business | architecture | framework | security | refactor.
  • modelTier: gemini-3.8-flash for rapid lint/scout, gemini-3.1-pro-preview for deep AST analysis and architectural durability reviews.
  • votingWeight: 1 to 5 (used in weighted consensus scoring).
  • blockingPower: If true, a failure or veto from this agent halts the pipeline immediately (e.g., Security Vulnerability or Scope Creep).
  • evalPrompt: Specialized domain constraints and rubric.

2-Tier Context Engine & Ripgrep Pipeline

<15ms Surface Extraction

Latency Optimization Through Multi-Layered Indexing

Naively feeding an entire monorepo into the LLM context window exhausts token quotas and inflates response latency. The Gemini CLI solves this with a two-tier strategy:

Tier 1: Surface Index (<15ms)

Extracted instantly on session launch and attached to every prompt header:

  • git status -s: Uncommitted diffs, modified branches, staging state.
  • Depth-2 Directory Skeleton: Structural overview without file bloating.
  • Active Workspace Root: Path resolution context for relative tools.
  • Consumes fewer than 450 tokens total.

Tier 2: On-Demand Ripgrep & AST

Invoked dynamically only when a subagent or coder needs deep knowledge:

  • Ripgrep native bindings: Sub-50ms regex searches across 100k+ lines.
  • AST Symbol Table: Function signatures, interfaces, and exported classes.
  • Mtime Cache: Never re-parses files whose timestamps have not changed.
  • Scoped strictly to relevant module boundaries.

Token Differential Masking & Output Truncation

Cost & Context Control

Preventing Context Pollution from Verbose Shell Outputs

When commands like npm test or cargo build produce 2,000 lines of console output, streaming the raw text into Gemini wastes tokens and causes hallucination drift. Gemini CLI applies intelligent Head/Tail masking:

Output Phase Preserved Content Purpose Storage Destination
Head 25 Lines First 25 lines of stdout/stderr Captures command flags, initialization warnings, and environment headers. Inlined in model prompt context
Truncated Middle [... 1,420 lines masked to save tokens ...] Prevents repetitive loop logs from burning token budget. Stored in .gemini/cache/artifacts/<job_id>.log
Tail 50 Lines Last 50 lines of stdout/stderr Captures stack traces, fatal assertions, exit codes, and summary tables. Inlined in model prompt context

/**
 * CouncilOrchestrator: Dispatches proposed code modifications to the active
 * declarative multi-agent council (PO, TechLead, Angular Specialist, Bug Hunter, DRY Finder).
 * Evaluates weighted consensus and enforces blocker vetoes with Gemini 3.1 Pro & 3.8 Flash.
 */
import { GoogleGenAI, ThinkingLevel } from '@google/genai';
import { AgentRegistry, AgentManifest } from './agent-registry.js';
import { EventBus } from '../types/events.js';

export interface ReviewVerdict {
  agentId: string;
  agentName: string;
  score: number; // 0 - 100
  passed: boolean;
  isBlocker: boolean;
  feedback: string;
  recommendedChanges?: string[];
}

export interface CouncilConsensusResult {
  overallScore: number;
  approved: boolean;
  blockersTriggered: string[];
  verdicts: ReviewVerdict[];
}

export class CouncilOrchestrator {
  constructor(
    private ai: GoogleGenAI,
    private registry: AgentRegistry,
    private eventBus: EventBus
  ) {}

  async evaluateDiff(
    userRequirement: string,
    fileDiffs: Record<string, string>
  ): Promise<CouncilConsensusResult> {
    const activeAgents = await this.registry.getActiveAgents();
    this.eventBus.emit('council:start', { agentCount: activeAgents.length });

    // Parallel evaluation across all active council agents
    const reviewPromises = activeAgents.map(agent =>
      this.executeSingleReview(agent, userRequirement, fileDiffs)
    );
    const settled = await Promise.allSettled(reviewPromises);

    const verdicts: ReviewVerdict[] = [];
    let totalWeightedScore = 0;
    let totalWeights = 0;
    const blockersTriggered: string[] = [];

    for (let i = 0; i < activeAgents.length; i++) {
      const agent = activeAgents[i];
      const outcome = settled[i];

      if (outcome.status === 'fulfilled') {
        const v = outcome.value;
        verdicts.push(v);
        totalWeightedScore += v.score * agent.votingWeight;
        totalWeights += agent.votingWeight;

        if (!v.passed && agent.blockingPower) {
          blockersTriggered.push(`[${agent.name}]: ${v.feedback}`);
        }
      } else {
        blockersTriggered.push(`[${agent.name}]: Execution failed: ${outcome.reason?.message}`);
      }
    }

    const overallScore = totalWeights > 0 ? Math.round(totalWeightedScore / totalWeights) : 0;
    const approved = overallScore >= 85 && blockersTriggered.length === 0;

    const result: CouncilConsensusResult = {
      overallScore,
      approved,
      blockersTriggered,
      verdicts
    };

    this.eventBus.emit('council:completed', result);
    return result;
  }

  private async executeSingleReview(
    agent: AgentManifest,
    requirement: string,
    fileDiffs: Record<string, string>
  ): Promise<ReviewVerdict> {
    const diffText = Object.entries(fileDiffs)
      .map(([file, diff]) => `--- ${file} ---\\n${diff}`)
      .join('\\n\\n');

    const prompt = [
      `You are: ${agent.name} (${agent.category})`,
      `Specialist Directives: ${agent.evalPrompt}`,
      `Original User Requirement: "${requirement}"`,
      `Proposed File Diffs:\\n${diffText}`,
      `Return JSON matching: { "score": number, "passed": boolean, "feedback": string, "recommendedChanges": string[] }`
    ].join('\\n\\n');

    // Invoking Gemini 3.1 Pro Preview or 3.8 Flash via modern GenAI SDK
    const res = await this.ai.models.generateContent({
      model: agent.modelTier,
      contents: [{ role: 'user', parts: [{ text: prompt }] }],
      config: {
        responseMimeType: 'application/json',
        thinkingConfig: {
          thinkingLevel: agent.modelTier.includes('pro') ? ThinkingLevel.HIGH : ThinkingLevel.LOW
        }
      }
    });

    const parsed = JSON.parse(res.text || '{}');
    return {
      agentId: agent.id,
      agentName: agent.name,
      score: parsed.score ?? 85,
      passed: parsed.passed ?? true,
      isBlocker: agent.blockingPower,
      feedback: parsed.feedback ?? 'Evaluation approved.',
      recommendedChanges: parsed.recommendedChanges || []
    };
  }
}

/**
 * ASTDuplicateFinder: Normalizes code tokens to perform structural AST similarity
 * comparisons against the existing symbol repository index, enforcing strict DRY.
 */
export interface DuplicationMatch {
  newSymbol: string;
  matchedExistingFile: string;
  matchedSymbol: string;
  similarity: number;
  recommendation: string;
}

export class ASTDuplicateFinder {
  normalizeTokens(code: string): string {
    return code
      .replace(/\/\*[\s\S]*?\*\/|\/\/.*/g, '') // strip comments
      .replace(/\s+/g, ' ')                    // collapse whitespace
      .replace(/const\s+|let\s+|var\s+/g, '')  // standardize variable tokens
      .trim();
  }

  analyze(
    newCode: string,
    existingSymbols: Map<string, { file: string; code: string }>
  ): DuplicationMatch[] {
    const matches: DuplicationMatch[] = [];
    const normNew = this.normalizeTokens(newCode);

    for (const [symName, entry] of existingSymbols.entries()) {
      const normExisting = this.normalizeTokens(entry.code);
      const sim = this.computeSimilarity(normNew, normExisting);

      if (sim > 0.80) {
        matches.push({
          newSymbol: 'Proposed Implementation',
          matchedExistingFile: entry.file,
          matchedSymbol: symName,
          similarity: Math.round(sim * 100),
          recommendation: `Import existing "${symName}" from ${entry.file} instead of re-implementing.`
        });
      }
    }
    return matches;
  }

  private computeSimilarity(a: string, b: string): number {
    if (a === b) return 1.0;
    const longer = a.length > b.length ? a : b;
    const shorter = a.length > b.length ? b : a;
    if (longer.length === 0) return 1.0;
    if (longer.includes(shorter)) return shorter.length / longer.length;
    return 0.25;
  }
}
/**
 * ModelConfigService: Resolves requested aliases ('auto', 'pro', 'flash', 'flash-lite')
 * to concrete Gemini 3.x models with automated 429 quota fallback cascade.

export const MODEL_DEFINITIONS = {
  PREVIEW_GEMINI_3_1_MODEL: 'gemini-3.1-pro-preview',
  LATEST_GEMINI_FLASH_MODEL: 'gemini-3.8-flash',
  BASE_GEMINI_FLASH_MODEL: 'gemini-3.5-flash',
  LATEST_GEMINI_FLASH_LITE_MODEL: 'gemini-3.5-flash-lite',
  LOCAL_GEMMA_MODEL: 'gemma-4-31b-it'
};

export class ModelConfigService {
  resolveModelId(alias: string, hasPreviewAccess: boolean = true): string {
    switch (alias.toLowerCase()) {
      case 'pro':
        return hasPreviewAccess
          ? MODEL_DEFINITIONS.PREVIEW_GEMINI_3_1_MODEL
          : MODEL_DEFINITIONS.BASE_GEMINI_FLASH_MODEL;
      case 'flash':
        return MODEL_DEFINITIONS.LATEST_GEMINI_FLASH_MODEL; // gemini-3.8-flash
      case 'flash-lite':
        return MODEL_DEFINITIONS.LATEST_GEMINI_FLASH_LITE_MODEL;
      case 'auto':
      default:
        return MODEL_DEFINITIONS.PREVIEW_GEMINI_3_1_MODEL;
    }
  }

  handleQuotaExhaustionFallback(currentModel: string): string {
    if (currentModel.includes('pro')) {
      // Instant fallback to high-throughput Flash
      return MODEL_DEFINITIONS.LATEST_GEMINI_FLASH_MODEL;
    }
    return MODEL_DEFINITIONS.LATEST_GEMINI_FLASH_LITE_MODEL;
  }
}
/**
 * ExecutionQueue: Throttles concurrent subagent tasks with detached background jobs,
 * output truncation, and disk artifact persistence.
 */
import * as fs from 'node:fs/promises';
import * as path from 'node:path';
import { EventBus } from '../types/events.js';

export class ExecutionQueue {
  constructor(
    private eventBus: EventBus,
    private maxConcurrency: number = 6,
    private artifactsDir: string = '.gemini/cache/artifacts'
  ) {}

  async executeParallel<T, R>(
    items: T[],
    worker: (item: T) => Promise<R>
  ): Promise<PromiseSettledResult<R>[]> {
    const results: PromiseSettledResult<R>[] = [];
    const executing: Promise<void>[] = [];

    for (const item of items) {
      const task = Promise.resolve()
        .then(() => worker(item))
        .then(val => { results.push({ status: 'fulfilled', value: val }); })
        .catch(err => { results.push({ status: 'rejected', reason: err }); });

      executing.push(task);

      if (executing.length >= this.maxConcurrency) {
        await Promise.race(executing);
      }
    }

    await Promise.all(executing);
    return results;
  }

  async maskOutputAndSaveArtifact(rawLogs: string, jobId: string): Promise<string> {
    await fs.mkdir(this.artifactsDir, { recursive: true });
    const logPath = path.join(this.artifactsDir, `${jobId}.log`);
    await fs.writeFile(logPath, rawLogs, 'utf8');

    const lines = rawLogs.split('\\n');
    if (lines.length <= 75) return rawLogs;

    const head = lines.slice(0, 25).join('\\n');
    const tail = lines.slice(-50).join('\\n');
    return `${head}\\n\\n[... ${lines.length - 75} lines masked to save tokens • Full logs: ${logPath} ...]\\n\\n${tail}`;
  }
}
