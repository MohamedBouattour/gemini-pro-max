sprints**. Every sprint is completely actionable, self-contained, and
accompanied by:

## 3. Execution Pipeline & opencode Automation

As prescribed by `RULE[user_global]`, each sprint file serves as the strict
execution context for the CLI execution agent. Because `opencode` uses `run`
with the `--file` flag:

```bash
# Execute Sprint 1 (Autonomous execution with attached sprint specification)
opencode run --auto "Execute Sprint 1 according to the attached specification" --file sprint1.md

# Verify Sprint 1 unit & integration tests
npm test -w @google/gemini-cli-core

# Execute Sprint 2
opencode run --auto "Execute Sprint 2 according to the attached specification" --file sprint2.md

# Or in interactive mode:
opencode run -i "Execute Sprint 1" --file sprint1.md
```
